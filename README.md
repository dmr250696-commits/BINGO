# Bingo TV

Crée des grilles de bingo 5×5 (24 cases + 1 case gratuite au centre) pour jouer pendant tes émissions préférées.

- Nouvelle grille : un titre + 24 cases
- Reprendre une grille déjà créée : jouer, modifier ou dupliquer
- Détection automatique des lignes (horizontales, verticales, diagonales)
- Fonctionne hors ligne, données gardées sur l'appareil

Application web installable (PWA) : un seul code pour Android et iOS.

## Mise en ligne avec GitHub Pages
1. Crée un dépôt GitHub et envoie-y ces fichiers à la racine.
2. Dépôt > Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Ouvre l'adresse `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Installer sur le téléphone
- **Android (Chrome)** : menu ⋮ > « Installer l'application ».
- **iPhone (Safari)** : bouton Partager > « Sur l'écran d'accueil ».
